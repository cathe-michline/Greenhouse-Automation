# 🌿 Greenhouse Automation (IoT)

**Greenhouse Automation using IoT**

Modern greenhouse and terrace farming face challenges such as pest control, crop diseases, extreme temperature and humidity, and inefficient irrigation. These factors directly impact crop yield and productivity.

With **IoT-powered automation and real-time monitoring**, farmers can efficiently control greenhouse conditions, improve crop quality, and maximise yield with minimal manual effort. This system enables easy-to-use automated controls and remote monitoring for sustainable and hassle-free greenhouse management.

---

## 🚀 Proposed Solution

We developed an **automated greenhouse control system** that:
- Maintains **optimal and consistent temperature and humidity**
- Helps prevent **disease-causing factors** such as algae and mildew  
- Monitors **soil nutrients** to support healthier plant growth  
- Promotes sustainability by suggesting **organic fertilizers** as alternatives to chemical fertilizers  
- Aligns with the **UN Sustainable Development Goal: Affordable and Clean Energy**

---

## 🛠️ Key Features
- Real-time monitoring of temperature, humidity, and soil moisture  
- Automated irrigation control  
- Mobile-based monitoring using IoT dashboard (Blynk)  
- Sustainable fertilizer recommendations
